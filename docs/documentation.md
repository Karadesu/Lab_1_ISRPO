# Документация проекта

## Общее описание

Проект представляет собой набор функций на языке программирования Python для вычисления 
площади и периметра простых фигур:
окружности, прямоугольника и квадрата.

Каждая фигура вынесена в отдельный файл:

- `circle.py` - окружность;
- `rectangle.py` - прямоугольник;
- `square.py` - квадрат;

Все функции принимают значения `int` или `float` и возвращают
число `float` или `int`. 
Проект использует стандартную
библиотеку `math`.

## Описание функций

### circle.py

#### `area(r)`

Вычисляет площадь окружности по формуле `math.pi * r*r`.

**Параметры:**
- `r` (int | float) - радиус окружности.

**Возвращает:** `float` - площадь окружности.

**Пример вызова:**
```python 
>>> from circle import area
>>> area(2)
12.566370614359172
>>> area(3.7)
43.00840342764427
```

#### `perimeter(r)`

Вычисляет периметр окружности по формуле `2 * math.pi * r`.

**Параметры:**
- `r` (int | float) - радиус окружности.

**Возвращает:** `float` - периметр окружности.

**Пример вызова:**
```python 
>>> from circle import perimeter
>>> perimeter(5)
31.41592653589793
>>> perimeter(3.7)
23.24778563656447
```

### rectangle.py

#### `area(a, b)`

Вычисляет площадь прямоугольника по формуле `a * b`.

**Параметры:**
- `a, b` (int | float) - стороны прямоугольника.

**Возвращает:** `int | float` - площадь прямоугольника.

**Пример вызова:**
```python 
>>> from rectangle import area
>>> area(2, 5)
10
>>> area(2.5, 3)
7.5
>>> area(3.2, 5.2)
16.64
```

#### `perimeter(a, b)`

Вычисляет периметр прямоугольника по формуле `(a + b) * 2`.

**Параметры:**
- `a, b` (int | float) - стороны прямоугольника.

**Возвращает:** `int | float` - периметр прямоугольника.

**Пример вызова:**
```python 
>>> from rectangle import perimeter
>>> perimeter(2, 6)
16
>>> perimeter(2.5, 5)
15
>>> perimeter(2.5, 3.6)
12.2
```

### square.py

#### `area(a)`

Вычисляет площадь квадрата по формуле `a * a`.

**Параметры:**
- `a` (int | float) - сторона квадрата.

**Возвращает:** `int | float` - площадь квадрата.

**Пример вызова:**
```python 
>>> from square import area
>>> area(6)
36
>>> area(1.6)
2.56  
```

#### `perimeter(a)`

Вычисляет периметр квадрата по формуле `4 * a`.

**Параметры:**
- `a` (int | float) - сторона квадрата.

**Возвращает:** `int | float` - периметр квадрата.

**Пример вызова:**
```python 
>>> from square import perimeter
>>> perimeter(7)
28
>>> perimeter(2.2)
8.8
```
